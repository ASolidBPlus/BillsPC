# Console sprite credits

Pixel-art console sprites in this directory are by **AloneAgainstPixels**
(DeviantArt). Used in pokeportal as the visual chrome between the
source and destination panes.

## Sprites

- `gbc.png` (33 × 52) — single Game Boy Color (middle-middle teal variant)
- `gba.png` (54 × 32) — single Game Boy Advance (middle-middle indigo variant)
- `gbc-r{0..2}c{0..2}.png` (33 × 52 each) — full 9-variant colour set,
  cropped from the original 101 × 158 spritesheet. Position naming is
  `r{row}c{col}` from the source sheet's 3×3 layout.
- `gba-r{0..2}c{0..2}.png` (54 × 32 each) — full 9-variant colour set,
  cropped from the original 163 × 97 spritesheet.

The 9-variant sets back the in-app theme picker (click a console in
the workbench to open it).
