# Gen 3 party icons — pret/pokeemerald

Source: https://github.com/pret/pokeemerald — `graphics/pokemon/<species>/icon.png`

Canonical in-game GBA party icons (32×32, 2-frame vertical strip)
extracted from the pokeemerald disassembly project. 386 files (ndex
1..386 = Gen 3 national dex). Animated via CSS keyframes (see
`.party-icon-gen3` in `style.css`).

pret/pokeemerald is BSD-3-Clause. Sprite art is from the original
Pokémon Emerald game (© Game Freak / Nintendo / The Pokémon Company)
— used here as nominal fair-use reference, mirroring the rest of the
PokéAPI / PKHeX sprite usage in the existing `gen1/`, `gen2/`, `gen3/`
directories.
