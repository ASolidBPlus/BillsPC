# Gen 1/2 party icons — SoupPotato (Sour Crystal)

Source: https://github.com/SoupPotato/sourcrystal — `gfx/icons/`

These are the bouncing 16×16 party icons from the Sour Crystal ROM hack
by SoupPotato. 251 files (ndex 1..251), one per Gen 1/2 species. Each
file is a 16×32 vertical strip = 2 frames stacked, animated via CSS
keyframes (see `.party-icon-gen2` in `style.css`).

The Sour Crystal repo has no LICENSE file. The README credits the sprite
art to SoupPotato. Used here unmodified except for the rename from
species-name to numeric ndex. If pokeportal becomes publicly hosted,
attribution should be retained and the SoupPotato repo linked from the
in-app sprite credits section.
