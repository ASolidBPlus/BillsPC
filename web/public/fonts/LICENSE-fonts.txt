# pokeportal font assets

`pokemon-gb.woff2` is **Pokemon GB** by Pokemon Perler (Aaron D.
Gillespie), the canonical thin-stroke 8×8 pixel font matching the
Game Boy Pokemon games' in-game text rendering. Released as freeware
(no usage restrictions), sourced from a public Godot project mirror
on GitHub at fetch time and converted from TTF → woff2 via fonttools.

Original PostScript name: `PokemonGB`, version 1.000;pyrs.

This replaces the earlier Press Start 2P substitute that pokeportal
shipped while no Pokemon GB mirror was reachable. Press Start 2P
worked but its double-pixel-stroke glyphs are visibly chunkier than
the in-game font, which made the stat-screen modal labels read as
"bolded" next to the baked-in template labels. Pokemon GB matches the
in-game text exactly.

`pokemon-gb-press-start-2p.woff2.bak` is the prior Press Start 2P
binary, kept on disk in case Pokemon Perler's font ever becomes
unavailable.

`pokemon-emerald.woff2` is **Pokemon Emerald** by aztecwarrior28
(FontStruct, 2021) — a fan-made TTF recreation of the Game Boy
Advance Pokemon in-game font (used in Ruby/Sapphire/Emerald and
FireRed/LeafGreen text rendering). Used by the FR/LG-style "AFTER"
stat-screen panel. Sourced from a public Godot project mirror on
GitHub at fetch time and converted from TTF → woff2 via fonttools.

Original PostScript name: `PokemonEmerald`. Copyright notice in the
font: "Copyright aztecwarrior28 2021". FontStruct fonts default to
CC-BY-SA distribution unless otherwise marked; we treat this as
CC-BY-SA and credit the author here.
