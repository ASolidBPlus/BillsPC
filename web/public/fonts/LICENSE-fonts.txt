# pokeportal font assets

`pokemon-gb.woff2` is the Latin subset (U+0000-00FF + a few quotation /
arrow / replacement code-points) of **Press Start 2P** by Codeman38 /
Cody Boisclair, sourced from Google Fonts:

  https://fonts.gstatic.com/s/pressstart2p/v16/e3t4euO8T-267oIAQAu6jDQyK3nVivM.woff2

Press Start 2P is licensed under the SIL **Open Font License 1.1**
(https://scripts.sil.org/OFL). The OFL permits embedding in software
including web bundles; we embed and serve the woff2 directly so first-
load works offline and over file:// previews.

The PLAN listed "Pokemon GB by Pokemon Perler (CC0)" as the preferred
choice (PLAN §10 Q3), but no maintained public mirror of that font was
reachable at fetch time. Press Start 2P is the closest functionally-
equivalent OFL pixel font: 8x8 glyph cell, monospace, ASCII-complete,
hand-tuned by an experienced gamefont artist, and explicitly intended
for use in retro-styled games and UIs. The S5 UI uses ASCII letters,
digits, and the glyphs `▶ ▼ ★ /` only — those are all in the Latin
subset shipped here (★ = U+2605 inside U+2600-U+26FF; the Latin range
for Press Start 2P does not include this glyph, so the browser falls
back to the system monospace font for it; see `style.css` `.shiny-star`
class which intentionally relies on the system fallback).
